##  About The Project

**Smart Seat Reservation & Allocation System** is a web-based application developed to simplify participant registration, batch organization, seat reservation, and seating allocation.

The system provides a simple interface through which participants can be managed and seats can be allocated in an organized manner. The final seating arrangement can also be displayed in a clear cinema-style layout.

The project is built using **HTML, CSS, PHP, and JSON**, and can be run locally using **XAMPP and Apache**.

---

## ✨ Features

### 👤 Participant Management
- Add new participants
- View participant information
- Delete participants
- Maintain organized participant records

### 💺 Seat Reservation & Allocation
- Allocate available seats to participants
- Maintain organized seating arrangements
- Prevent duplicate seat allocation
- Manage seating information through JSON data

### 🪑 Seating Visualization
- Display the complete seating arrangement
- Cinema-style seating layout
- Clearly identify allocated seats
- Easy-to-understand visual representation

### 🎨 User Interface
- Clean and simple web interface
- Custom CSS styling
- Easy navigation
- User-friendly design
